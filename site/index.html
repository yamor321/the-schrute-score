How this is calculated

  1. A coding score from independent benchmarks

    Each model gets a coding score from 0 to 100, measured independently by Artificial Analysis:

    • Only near-top models qualify

    • A price per million tokens

    • Among the qualifiers, value decides

      value = coding score ÷ price per 1M tokens

      Every model that cleared the bar is already strong. What separates them is how much you pay for that strength. If two models score 76 and 80, and one costs $2 while the other costs $30, the first wins: you give up a few points and pay 15 times less. The best model overall ranks first only if nothing close to it is much cheaper.
