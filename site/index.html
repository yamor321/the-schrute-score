How this is calculated

  1. A coding score from public benchmarks

    Each model gets a coding score from 0 to 100, built from these coding benchmarks measured independently by Artificial Analysis:

      Some benchmarks report 0–100 and others 0–1, so everything is converted to 0–100 first. If a model hasn't been tested on one of them yet, we don't count that as a zero. Instead, the benchmarks it does have share the weight. The table shows which benchmarks each model was scored on.

    • A price per million tokens

    • Value = coding score ÷ price

      value = coding score ÷ price per 1M tokens

      A higher value means more coding capability for each dollar. A model scoring 60 at $2 has a value of 30. A model scoring 40 at $0.50 has a value of 80. The second one is weaker but gives you more for the money. The value score is not a quality ranking. To see raw quality, look at the coding score on its own, or at the vertical axis of the price-vs-score chart.
